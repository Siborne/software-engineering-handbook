# 前言

> 千里之行，始于足下

## 为什么建立这个知识库？

从接触计算机到现在，我写过很多代码，也学过很多知识。

但随着学习越来越深入，我却发现自己出现了几个问题。

首先，是**输出能力越来越弱**。

很多知识自己明明理解了，却很难用自己的语言讲给别人听。无论是面试、分享还是日常交流，经常会出现"知道是什么，但说不出来"的情况。

其次，是**AI带来的依赖**。

AI 极大提高了学习和开发效率，但也让我越来越少主动组织语言、整理思路。久而久之，写作能力、文档能力和表达能力都有所下降。

最后，是**知识越来越碎片化**。

每天都会学习新的知识点，看过很多文章，也收藏了很多链接，但真正需要的时候，却常常想不起在哪里、为什么学、以及它与其他知识之间有什么联系。

于是，我决定建立这个知识库。

它不仅是一份学习笔记，更是一份思考记录。

我希望通过持续输出，把零散的知识整理成体系，把学过的内容真正变成自己的能力。同时，也希望能够帮助后来者少走一些弯路。


**这个知识库，便因此诞生。**

## 如何阅读

这个知识库并不是一本教材。

它更像是一位同行者，在记录自己的学习过程，也分享一路上的思考与踩过的坑。

<u>因此，你不需要从第一页开始阅读</u>。

当你遇到某个知识点时，可以直接查阅对应章节；如果你正在系统学习，也可以按照目录逐步阅读。

在每篇文章中，我都会尽量回答三个问题：

- **它是什么（What）**
- **为什么要这样做（Why）**
- **实际应该怎么做（How）**

相比于死记硬背，我更希望帮助你理解知识背后的逻辑。

因为我始终相信：

> 真正的学习，不是记住答案，而是建立自己的思维方式。

<u>希望这份知识库，能够陪伴你一起成长。</u>
