# Rebuttal

> Rebuttal 不是和审稿人争输赢，而是在有限篇幅内把事实、证据和修改说清楚。

收到审稿意见后，最容易出现的反应是逐条辩解：审稿人误解了，方法其实很新，结果已经足够好。另一种极端是全部接受，却没有说明哪些问题真的能改、哪些限制客观存在。两种回应都会浪费一次澄清论文的机会。

Rebuttal 的核心任务是审计论文的论证：审稿人指出的问题是否真实存在？如果存在，能否补实验或修改表述？如果不存在，能否用论文中的位置、数据或定义清楚说明？每一条回应都应该让审稿人更容易判断这篇论文的贡献。

## 本章目标

学完本章，你应该能够：

- 把审稿意见分类为事实错误、表述不清、证据不足和价值判断分歧。
- 根据影响大小分配 Rebuttal 篇幅，不漏掉关键问题。
- 用“结论、证据、修改、位置”组织逐点回应。
- 在无法补实验时诚实说明限制，而不是模糊承诺。
- 写出准确、克制、可核查的 AC Message。

## 先分类，再分配篇幅

不要按审稿人编号平均分配篇幅。先读完全部意见，把问题按影响和可回应程度分类：

| 类型 | 特征 | 回应重点 |
| --- | --- | --- |
| 事实错误 | 审稿人引用了错误数字、方法或论文内容 | 直接指出事实，给出论文行号、表格或补充证据 |
| 表述不清 | 论文写了，但审稿人没有理解 | 承认表述问题，说明原意，并给出修改后的写法 |
| 证据不足 | 缺少 Baseline、消融、场景或效率数据 | 能补就补；不能补要说明原因和结论边界 |
| 价值分歧 | 对重要性、Novelty 或适用范围有不同判断 | 重申贡献与问题，比较最接近的工作，避免重复口号 |
| 超出范围 | 要求与论文目标无关的任务或系统能力 | 说明范围边界，必要时作为 Future Work |

同一类问题可能来自多位审稿人。可以先写一段共同回应，再在个人回复中引用，避免重复消耗篇幅。真正影响录用判断的问题应该优先得到完整证据，小错误则简洁承认并说明修改。

## 逐点回应的结构

每条回应尽量包含四部分：先给结论，再给证据，然后说明论文如何修改，最后指出修改位置。这样审稿人不需要在一大段文字里寻找答案。

```text
回应：我们同意/不同意这个判断。
证据：给出实验、定义、表格、行号或引用。
修改：已经补充/重写/澄清了什么。
位置：见 revised Section X、Table Y 或 Line Z。
```

如果审稿人误解了论文，不要只写“审稿人看错了”。更有效的表述是承认原文不够清楚，然后说明实际设定，并给出修改前后的差异。这样既维护事实，也降低再次误读的概率。

## 常见质疑怎么回应

**Novelty 不足。** 不要只重复“我们的方法很新”。先明确论文与最接近工作的差异：是问题定义不同、假设不同、机制不同，还是评价目标不同。如果贡献是组合式创新，要说明组合为什么不是简单拼接，以及哪个实验证明了组合产生了新效果。

**提升有限。** 先检查比较是否公平。提升是否在多个数据集上稳定？是否在更难或更真实的设置下更明显？是否带来效率、鲁棒性或通用性的额外收益？如果提升确实有限，应明确说明适用边界，而不是把统计噪声包装成显著改进。

**实验不充分。** 能在 Rebuttal 周期完成的实验优先补。无法完成的，要解释资源、数据或时间限制，并说明现有证据能支持到什么程度。不要承诺一个无法验证的“final version will show”，除非确实有计划并且审稿人能据此判断。

**事实错误。** 如果论文中的数字、定义或引用确实有误，直接承认、感谢指出并说明修正。如果是审稿人理解错误，引用原文位置和上下文澄清。两种情况都不要回避。

**写作、语法和引用问题。** 大多数可以直接承认并修改。若同类问题很多，可以集中说明已经统一检查的范围，而不是逐条写“fixed”。

::: danger 不要伪造证据或隐瞒限制
Rebuttal 中的每个数字、引用和实验设置都必须可核查。为了争取评分而编造结果、删除不利条件或把失败实验描述成成功，会破坏研究诚信，也可能在后续复现中暴露。
:::

## AC Message 怎么写

只有在审稿意见存在明显事实错误、自相矛盾、超出评审范围或违反评审规范时，才需要给 AC 写单独说明。AC Message 应该短、具体、可核查，不要情绪化评价审稿人。

- 先说明论文编号和对应审稿人。
- 指出具体问题发生在哪条意见、哪张表或哪一行。
- 给出事实依据和论文中的对应位置。
- 说明你希望 AC 关注什么，而不是要求 AC 直接给分。

例如，审稿人声称论文没有与某个 Baseline 比较，但该 Baseline 已在 Table 2 中出现，可以指出具体表格、行和方法名称。若审稿人给出相互矛盾的评价，引用两条意见并说明矛盾点即可，不需要推断审稿人的动机。

## 常用表达

回应时优先使用中性、具体的英语表达：

- 感谢并确认：`We thank the reviewer for pointing this out. We agree that ...`
- 澄清误解：`We have clarified this point in Section X. In our setting, ...`
- 引用证据：`As shown in Table Y, ...`
- 说明修改：`We have added ... to the revised manuscript.`
- 说明范围：`This is outside the scope of the current paper because ...`
- 承认限制：`This is a limitation of our current evaluation, and we have discussed it in Section X.`

避免 `The reviewer is wrong`、`Obviously`、`As we already stated` 这类带有对抗意味的表达。即使审稿人的判断确实错误，也要让事实和证据承担主要论证。

## 总结

Rebuttal 是一场有约束的证据沟通：

- 先分类问题，再按影响分配篇幅。
- 每条回应说清结论、证据、修改和位置。
- 能补实验就补，不能补就说明限制，不伪造、不模糊承诺。
- 对事实错误要澄清，对价值分歧要回到问题和贡献。

如果只能记住一件事：让审稿人读完回应后，能够明确知道哪些问题已经解决，哪些仍然存在。
